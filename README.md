# НКА — сайт независимой коллегии адвокатов

Одностраничный сайт коллегии адвокатов (Санкт-Петербург, ул. Некрасова, 36):
арбитражные, экономические и уголовные дела экономической направленности.

Сборка не нужна — чистый HTML/CSS/JS в одном файле `index.html` (шрифты — с
Google Fonts, 3D-печать в hero — Three.js с CDN). Открывайте файл в браузере
или разверните на любом статическом хостинге.

## Как запустить локально

```bash
python3 -m http.server 8000
```

## Карта

Блок «Как нас найти» использует встроенный виджет Яндекс.Карт (`iframe`) и
ссылку «Проложить маршрут», которая строит маршрут от посетителя до адреса
через Яндекс.Карты. Координаты и адрес заданы в разметке секции `#find-us` —
при переезде офиса обновите `ll=`/`pt=` в `src` iframe и `rtext=` в ссылке
маршрута.
